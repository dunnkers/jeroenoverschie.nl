Privacy

Jeroen Overschie

I really like the web: the web is a free, open and decentralized place to share content and thoughts. It has been since its origins. However, we have since gotten a bit crazy with tracking and monitoring. Understanding how customers interact with your product or site is nice and valuable- but extending tracking reach beyond sufficient means is too much.

This website has:

  • 0 tracking cookies
  • 0 fingerprinting, session recording, keystroke logging
  • 0 unsolicited browser storage uses
    • ... your browser can store a lot of information, just like cookies. There are concepts like sessionStorage and localStorage (MDN Web Storage API) which act like key-values stores but in your browser, and there's even in-browser databases you can use like IndexedDB (MDN IndexedDB).
    • That said: these technologies are great. So let's use them for the right thing.
  • 1 third-party script
    • ... which is the: Cloudflare Web Analytics beacon. A privacy-first and lightweight solution for web analytics.

Don't take my word for it. Check out these privacy reports for this website:

  • HTTP Observatory (Mozilla, MDN)
  • Blacklight (The Markup, non-profit)
  • Webbkoll (5th of July Foundation, Sweden)

And, as a matter of fact, the source of this website is openly accessible on GitHub at dunnkers/jeroenoverschie.nl. Feel free to see how this website is built.

Additionally, you might protect yourself against trackers by your own means. You can do so by using browser extensions like 1Blocker (Safari), StopTheMadness (Safari), changing your browser settings itself (Safari). If you aren't on Safari, there should be similar alternatives. by using a VPN that blocks trackers. VPNs can often also block ads, which you will get as a bonus 😛.

Admittedly, a privacy page for a static blogging website like this is completely overkill: there are no user sign-ups, forms or data to protect and keep safe. So, besides informing you on the practices of this website, you can see this page as a manifesto too. This is how I would like to see the web- transparent and honest. So.. why not start with my own web presence to begin with? It is always easier to say than to do- so let me do the latter.
